# Manual de uso — Sistema de Trazabilidad Documental (DAI)

Manual del sistema de trazabilidad documental de la Dirección de Auditoría Interna (DAI),
Ministerio de Finanzas Públicas. Está dividido en una introducción común y un capítulo por cargo,
porque cada cargo ve y puede hacer cosas distintas dentro del sistema.

## Cómo leer este manual

1. **[00 — Introducción](00-introduccion.md)** — léela primero sin importar tu cargo: qué es el
   sistema, cómo iniciar sesión, qué es el semáforo, la bitácora, el flujograma y cómo exportar
   una hoja de ruta. Estos conceptos se usan en todos los capítulos siguientes.
2. Después, lee solo el capítulo de tu cargo:
   - **[01 — Auditor](01-manual-auditor.md)**
   - **[02 — Subjefe](02-manual-subjefe.md)**
   - **[03 — Jefe](03-manual-jefe.md)**
   - **[04 — Subdirector](04-manual-subdirector.md)**
   - **[05 — Director](05-manual-director.md)**

Cada capítulo cubre exactamente lo que ese cargo puede hacer hoy en el sistema — no incluye
funciones que todavía no existen en la interfaz, aunque estén mencionadas en el documento de
diseño del sistema (`prompt-maestro-trazabilidad-dai.md`).
